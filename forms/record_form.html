Actuator record form

Describe one actuator (one finger's worth) so the workshop tool can try it as a finger. Type datasheet numbers, paste measured tables in whatever units you have, or both. Nothing leaves your browser: the button at the bottom downloads a record file (JSON) that you load with --record your_file.json.

The frame. All directions are in the actuator's own frame: X runs from the fixed base to the tip, +Y is the main way it moves sideways (the way a bender bends). Z completes a right-handed frame. An extender moves along +X, a contractor along −X, a bender mostly along +Y.
