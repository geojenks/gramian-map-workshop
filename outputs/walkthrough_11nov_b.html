From an actuator or a hand to a verdict

A walk through one stored run of the whole chain: actuator in, record, hand, task, verdict. Pick a way in and read down.

This page runs nothing. Each command is shown as it ran, with its exit code, wall time and output read from the logs in outputs/run_through_11nov/logs/. Verdicts are read from tables.md in that folder.

In the commands, <hands env> is the Python environment with the hands extra (MuJoCo), <analysis env> is one that has matplotlib, <clone> is the fresh clone, and rt_out/ is the scratch folder the run wrote to. Run from the clone's top folder.

The run's files are stored under other names than the commands use: rt_out/r0/*.json records are in records/, rt_out/*.json description files in hand_descriptions/, data/hands/<name>/ in hands/<name>/, and rt_out/leaders and rt_out/results in leaders/ and results/.

The laptop was shared with other jobs, so the times are a guide only. Simulated magnitudes are comparative, not predictive.
