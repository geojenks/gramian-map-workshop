Can N copies of your actuator hold, and turn, a ball in a cup?

A small tool from our ARIA dexterous soft robotics work. Give it a soft actuator's record (datasheet numbers or a measured table) and it says, for each arrangement of fingers, whether the task can be done and, if not, why: direction, friction, or strength.

Simulation and records only: comparative, not predictive. Record forces are uncalibrated, so strength is shown but never scored.

Try it with no install

  • Record form: type datasheet numbers or paste a measured table in whatever units you have, and download a record file. It runs in your browser.
  • Cup hold: which actuators hold the ball, with N = 1 to 8 fingers and four ways of mounting them. Hover any cell for the reason.
  • Cup turn: the same cup turned by a travelling make/break wave; which fingers can drive the turn and which can only hold.
  • Cup hold with passive stiffness: each finger may also resist as a spring, within 2 mm of deflection.
  • Can this hand follow the leader?: rigid and human hands checked against a recorded wave gait.

Run it on your own actuator

You need Python 3.9 or newer and git.

git clone https://github.com/geojenks/gramian-map-workshop
cd gramian-map-workshop
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e .
python demos/cup_hold.py --record my_actuator.json
python demos/cup_turn.py --record my_actuator.json

To check rigid robot hands as well (Allegro, Shadow, LEAP and Linker's public L20), add MuJoCo and fetch the hand models:

pip install -e ".[hands]"
python tools/fetch_hands.py

The README explains how to read a result, what data a record needs, and where every number comes from. Each push is checked on clean Linux and Windows machines.
